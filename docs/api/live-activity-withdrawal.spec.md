# 회원 탈퇴 시 Live Activity 영향 축제 잠금

회원 탈퇴 트랜잭션은 탈퇴자의 크루 소속 축제와 영향받는 깃발의 축제 ID를 합쳐 중복을 제거합니다. `admin_festivals`의 해당 행을 ID 오름차순으로 `FOR UPDATE` 잠근 뒤 기기 삭제와 사용자 삭제를 진행합니다. 깃발의 팔로워·신고 수는 사용자 삭제로 연관 행이 제거된 **후** 다시 계산하며, 공개 팩 동기화와 남은 기기의 Live Activity 갱신 예약도 같은 트랜잭션에서 수행합니다.

이 잠금 순서는 탈퇴 중 축제 팩 갱신과 기기 삭제가 겹칠 때의 P1 경쟁을 좁히기 위한 것입니다. APNs 발송 지연, 트랜잭션 밖 outbox, 탈퇴자의 마지막 활동 종료 보장은 별도 과제입니다.
