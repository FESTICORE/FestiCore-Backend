# 서울뮤직페스티벌 추가 아티스트 사진 수집

## 목적

발견된 서울뮤직페스티벌의 출연진 중 사진이 없는 권진아와 옥상달빛의 공식 실사진을 서버에 저장하고 상세 API에서 제공한다.

## 출처와 식별

| 출연진 | 공식 출처 | 검증 기준 |
| --- | --- | --- |
| 권진아 | Antenna 아티스트 페이지 | `og:url`, 한글·영문 이름, 단일 본문 `org_image` |
| 옥상달빛 | Poclanos 아티스트 페이지 | 제목·H1 이름, `artist-img-wrap`의 사진 |

사진 URL은 코드나 migration에 고정하지 않는다. 매일 `artist-image` 소스가 현재 페이지를 다시 읽고, 허용된 HTTPS 이미지 호스트·경로와 robots 정책을 통과한 사진만 기존 이미지 저장소에 저장한다. 사진이 없는 경우 다른 아티스트나 공연 포스터로 대체하지 않는다. 옥상달빛 공식 페이지 사진은 과거 업로드여서 최근 촬영으로 표시하지 않는다.

## 연결 정책

두 소스의 `festivalSourceUrl`은 서울뮤직페스티벌 발견 상세의 `https://ticket.yes24.com/Perf/60368`과 일치시킨다. 축제와 아티스트, 수집 페이지와 이미지 원본 경로가 모두 일치하는 저장 사진만 공개 상세·타임테이블·이미지 다운로드에 노출한다. 관리자 화면에서 소스를 수정할 때도 이 조합을 확인한다.

너드커넥션은 Mint Paper의 사진 저장 호스트가 `robots.txt`에 403을 반환하고 부산국제록페스티벌 공식 페이지도 403을 반환해 이번 등록에서 제외한다. 수집 가능한 공식 사진 소스가 검증되면 별도 등록한다.

## 검증

- 두 공식 페이지의 실제 HTML에서 각각 하나의 사진 URL이 추출되는지 확인한다.
- 다른 아티스트·축제·출처, 외부 호스트, 검색 매개변수는 거부한다.
- migration이 2개 소스만 등록하고 이미지를 하드코딩하지 않는지 확인한다.
- CI의 단위 테스트, E2E, 빌드, migration 검증을 통과한 뒤 개발 서버의 두 아티스트 `imageUrl`과 이미지 응답을 확인한다.
