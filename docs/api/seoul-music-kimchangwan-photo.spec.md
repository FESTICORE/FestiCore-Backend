# 서울뮤직 김창완밴드 공식 사진 수집

## 출처 및 범위

- 출연진 이름과 사진의 결합은 뉴욕한국문화원의 [2025 K-Music Night 공연 페이지](https://kr.koreanculture.org/performing-arts/2025/08/06/kmusic-night/kor)의 `▲ 김창완밴드` 캡션 바로 앞 이미지 블록으로 검증한다.
- 해당 페이지는 **2025년 다른 공연의 프로필 사진 출처**다. 서울뮤직페스티벌 2026 공연 사진으로 표시하지 않는다.
- 페이지의 명시적 재사용·저장 금지 문구는 확인되지 않았다. 별도 사진 이용허락이 명시된 것은 아니므로 출처 URL을 보존하고 삭제 요청 시 소스를 비활성화할 수 있어야 한다.

## 수집 및 공개

- 매일 등록된 `artist-image` 소스가 현재 HTML의 단일 `750w` 사진 URL을 읽는다. 코드와 migration에는 이미지 URL을 고정하지 않는다.
- 이름이 모호하거나 인접한 사진 블록이 없으면 수집하지 않는다. 지정된 Squarespace CDN 호스트와 페이지 콘텐츠 경로만 허용하고, 이미지 robots 및 크기 제한과 기존 저장소 정책을 적용한다.
- 공개 상세·타임테이블·이미지 다운로드는 서울뮤직페스티벌 YES24 상세 URL, 김창완밴드 이름, 공식 출처 URL과 저장된 이미지 원본 패턴이 모두 일치할 때만 허용한다.

## 검증

- 실제 페이지 HTML에서 현재 사진 URL을 동적으로 추출한다.
- 다른 이름·사진 순서·호스트·URL 형식은 거부한다.
- migration 충돌 및 비활성 소스 검사를 단위 테스트와 CI 데이터베이스 검사로 확인한다.
- 배포 후 공개 상세의 `imageUrl`과 이미지 응답을 검증한다.
