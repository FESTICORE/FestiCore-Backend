# 관리자 개인정보처리방침 편집 API

## 목적

관리자 콘솔에서 현재 공개 중인 개인정보처리방침을 읽고 수정한다. 공개 주소는 `/api/v1/legal/privacy`이며 인증 없이 HTML을 제공한다.

## 계약

| 메서드 | 경로 | 권한 | 응답 data |
| --- | --- | --- | --- |
| GET | `/api/v1/admin/legal/privacy` | 관리자 viewer 이상 | `{ content, version, updatedAt }` |
| PUT | `/api/v1/admin/legal/privacy` | 관리자 owner | `{ content, version, updatedAt }` |

두 관리자 API는 기존 `{ code, data, message }` 응답 형식을 사용하고 `Cache-Control: no-store`를 설정한다. 쓰기 요청은 기존 관리자 출처 검사를 거쳐야 한다.

PUT 요청 본문: `{ "content": "## 제목\n\n본문", "expectedVersion": 0 }`. 본문은 일반 텍스트이며 `## `로 시작하는 줄을 제목, 빈 줄을 문단 경계로 사용한다. HTML 태그와 스크립트는 공개 페이지에서 이스케이프한다. 본문은 공백을 제거한 뒤 1~30,000자여야 한다.

최초 편집 전 GET은 코드에 포함된 기본 문서, `version: 0`, `updatedAt: null`을 반환한다. 저장 성공 시 버전이 1 증가하고 감사 기록에 이전/새 버전과 본문을 남긴다. 다른 관리자에 의해 버전이 바뀌었으면 409를 반환하며 저장하지 않는다. 빈 본문 또는 잘못된 버전은 400, 인증·권한·출처 오류는 401 또는 403이다.

공개 개인정보처리방침은 저장된 본문을 서버에서 렌더링하며, 캐시를 비활성화해 저장 후 새 요청에 최신 문서가 반영되도록 한다. 이용약관과 홈페이지는 이번 변경의 대상이 아니다.

## 검증

- 기본 문서 조회와 버전 반환
- 원자적 버전 검사, 감사 기록, 충돌 거부
- HTML 이스케이프와 공개 페이지의 `no-store`
- 관리자 viewer의 수정 거부와 owner의 수정 허용은 공통 관리자 인증 가드를 따른다.
