# 발견 축제 상세 조회와 공식 상세 수집

- `GET /api/v1/festivals/:id`는 목록의 `id`로 발견 축제 또는 발행 축제를 조회한다. 응답은 `{code,data,message}`이며 없는 ID는 404다.
- 발견 축제는 제목, 행사 날짜, 장소, 저장된 포스터 경로, 예매 출처, 공식 계정, 확인된 출연진과 출처를 제공한다. 확인되지 않은 무대·출연 시각은 `null` 또는 빈 목록으로 두며 추정하지 않는다.
- 발행 축제는 기존 공개 팩을 기반으로 상세를 반환한다. 앱은 오프라인 저장에 필요한 발행 팩을 별도 `/pack`에서 받는다.
- NOL의 자동 발견 소스는 현재 접근 차단으로 비활성화한다. YES24와 멜론티켓의 공개 목록 및 공식 상세 페이지를 크롤러 경계(HTTPS, 공개 IP, robots, 크기·시간 제한) 안에서 수집한다.
- 공식 인스타그램 링크는 행사 공식 사이트 또는 주최자가 직접 표시한 계정만 연결한다. 로그인/차단 우회 및 게시물 스크래핑은 하지 않는다.
- 출연진 사진과 상세 이미지는 저장·검증된 이미지에 한해서 공개 경로로 제공한다. 타임테이블은 공식 소스가 날짜·무대·시각을 명시한 경우에만 발행 팩으로 반영한다.

검증: 실제 공개 HTML 직접 파싱(원더리벳 출연진 40명·이미지 후보 35개, YES24 CDF 상세 1건), 상세 조회 200/404, 공개 이미지 접근 제한, 기존 목록/팩 회귀 테스트, CI 빌드 및 마이그레이션. 이 파싱 검증은 서버 DB 저장·정기 실행·배포 성공을 증명하지 않는다.
