# 서울뮤직 페스티벌 공식 아티스트 사진

- 공개 상세에 저장된 출연진 `폴킴`, `너드커넥션`과 축제 원본 `https://ticket.yes24.com/Perf/60368`을 정확히 연결한다.
- 폴킴 공식 홈페이지와 너드커넥션 소속사 프로필을 `artist-image` 소스로 등록한다. 매일 현재 페이지에서 사진 URL을 추출하며 특정 사진 URL은 저장하거나 고정하지 않는다.
- 페이지의 아티스트 식별 정보, 이미지 호스트와 경로, HTTPS, 이미지 다운로드 정책이 모두 통과해야 저장한다. 불일치·중복 후보는 건너뛴다.
- 마이그레이션은 이미 활성인 다른 아티스트 소스와 비활성 기존 소스가 있으면 중단한다. 기존 데이터를 덮어쓰지 않는다.
- 검증: 파서·마이그레이션 단위 테스트, ESLint, TypeScript 및 빌드. 실제 배포 후 공개 상세의 이미지 URL과 이미지 응답은 별도로 확인한다.
