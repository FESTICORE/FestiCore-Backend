# Mint Paper 공식 축제 수집

매일 KST 00:00 이후 `https://mintpaper.co.kr/festivals`의 공개 HTML을 수집한다. `__NEXT_DATA__`의 Apollo 상태에서 축제 ID·제목·기간·장소·표지 이미지 URL을 읽고 `festival.new` 제안으로 DB에 저장한다. 새 축제 ID를 발견하면 다음 예약 수집을 위한 상세 수집원을 자동 등록한다. 상세 페이지의 행사명과 인스타그램 계정명이 일치하는 경우에만 공식 계정 링크를 후보에 추가한다. 전역 footer의 주최자 계정과 라인업의 아티스트 계정은 행사 공식 계정으로 취급하지 않는다.

## 공개 계약

- `GET /api/v1/festivals`의 발견 항목에는 날짜·장소가 유효한 후보만 포함한다. 공식 행사 계정이 확인되면 `officialInstagramUrl`을 포함한다.
- 축제 날짜를 공연 시작 시각으로 변환하지 않는다. 상세 공연 시각이 없으면 타임테이블을 만들지 않는다.
- 표지 이미지는 원본 URL의 robots 규칙과 공개 주소·크기·형식을 검사한 뒤 서버 객체 저장소에 WebP로 저장한다. 저장된 이미지가 있으면 공개 목록의 `thumbUrl`에 `/api/v1/festivals/images/{imageId}.webp`를 반환한다. 아직 저장되지 않았으면 `null`이다.
- 원본 응답이 실패하거나 구조가 바뀌면 수집 실행을 실패로 기록하고 기존 제안을 삭제하지 않는다.

## 검증

- 공식 목록의 `Festival`/`UploadFile` 참조에서 제목·기간·장소·표지 이미지를 가져온다.
- 잘못된 JSON, 다른 사이트 URL, 날짜나 장소가 없는 행사는 공개 항목으로 만들지 않는다.
- 상세 `info`에 직접 연결된 행사 인스타그램만 저장하고 footer·아티스트 링크는 제외한다.
- 마이그레이션 후 예약 실행, 새 상세 수집원 등록, 제안 및 이미지 DB 저장, 개발 API 응답을 실환경에서 확인한다.
