# 원더리벳 공식 시간표 OCR 보강 (#135)

## 원본과 목표

- [amazarashi 공식 공지](https://apologies.jp/news/detail/811)에 연결된 2026-11-20 시간표 이미지를 기존 원더리벳 금요일 수집 소스에 연결한다.
- 인쇄된 시간 눈금 뒤 또는 다음 줄에 있는 출연진 텍스트를 OCR 검토 후보로 보관한다. 공연 행과 무대 배정은 관리자 검토 후에만 공개한다.
- 출연진 이름과 시각을 코드나 DB 마이그레이션에 직접 넣지 않는다. `22:00+`는 확정 종료 시각으로 해석하지 않는다.

## 검증

- 기존 OCR의 이전 줄 이름 읽기를 유지하고, 명시 설정된 시간표에서만 뒤쪽 이름을 읽는다.
- 금요일 공식 이미지 소스만 교체하며 토·일 원본은 유지한다.
- 재수집은 새 이미지의 OCR 결과와 관리자 검토가 필요하다. 로컬에 OCR 실행기가 없으면 실데이터 반영을 완료로 간주하지 않는다.
