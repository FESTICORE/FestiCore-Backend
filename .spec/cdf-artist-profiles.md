# COUNTDOWN FANTASY 출연진 공식 계정 연결 (#139)

- 원본: `https://www.mintpaper.co.kr/posts/4819` 공식 1차 라인업.
- 12월 31일 행의 12개 이름과 각 인스타그램 프로필 URL을 한 쌍으로 파싱한다. 푸터 계정과 해시태그는 제외한다.
- 공개 축제 상세의 `artists[].profileUrl`은 해당 공식 게시물에서 온 계정에만 제공한다.
- 최신 YES24 제안에 다른 출연진 목록이 있어도 공식 게시물의 계정 쌍은 별도 출처로 유지해 같은 이름에 연결한다. 잘못된 출처 URL은 해당 후보만 건너뛰고 목록 조회를 계속한다.
- `artists[].imageUrl`은 서버에 이미 검증·저장된 출연진 사진이 있을 때만 제공한다. 계정 URL이나 게시물 전체 포스터를 개인 사진으로 취급하지 않는다.
- 인스타그램의 현재 robots 규칙은 전체 경로 자동 수집을 금지하므로 프로필 사진을 서버에서 가져오지 않는다. 이 경로로 비어 있는 사진을 채우는 것은 범위 밖이다.

## 검증

- 12개 이름·계정 쌍과 푸터 제외, 잘못된 프로필 URL 거부.
- 공식 라인업 출처 표시가 없는 후보의 계정 정보 거부.
- 기존 저장 사진과 공식 프로필 URL을 함께 반환하고 새 사진을 추정하지 않음.
- 다른 출처의 최신 제안, 공식 URL의 apex/query 변형, 잘못된 출처 URL에 대한 회귀 검증.
