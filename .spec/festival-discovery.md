# 페스티벌 판매처 목록 수집

공개 티켓 판매처의 페스티벌 분류를 매일 KST 00:00 이후 서버에서 수집해 `festival.new` 제안으로 저장한다. 웹/앱의 `GET /api/v1/festivals`는 날짜와 장소가 검증된 발견 항목을 발행 축제와 함께 돌려준다.

## 소스와 판정

- 멜론티켓 페스티벌 카테고리 JSON: 분류값 `GENRE_CON_FESTIVAL`을 확인한 후 제목·상품 ID·공연 기간·장소를 읽는다. 해당 분류에는 일반 공연도 있으므로 제목의 축제 표시를 기본 조건으로 한다. 공식 행사 정보로 확인한 원더리벳과 카운트다운 판타지는 예외로 포함한다.
- YES24 페스티벌 분류의 공개 목록: 상품 ID·제목·기간·장소를 읽는다. 같은 제목 검증을 적용하고 상품 링크는 `https://ticket.yes24.com/Perf/{id}`로 구성한다.
- NOL은 공개 콘서트 목록에서 축제 항목을 수집하되, 판매 시작일을 행사일로 사용하지 않는다. 행사 날짜·장소가 없으면 공개 목록에 올리지 않는다.

원본 URL과 수집 실행·제안 이력은 DB에 보관한다. 동일 URL의 재수집은 변경된 후보만 제안하며, 빈/실패 응답이 기존 정상 제안을 삭제하지 않는다. 공개 목록은 검증된 HTTPS 티켓 URL만 포함한다.

## 검증

- 현재 공개 Melon 응답에 존재하는 원더리벳(`prodId=213793`)의 제목·`2026-11-20`~`2026-11-22`·`KINTEX HALL 7/8/9/10` 파싱
- YES24 페스티벌 카테고리의 행사 ID·기간·장소 파싱과 중복 URL 제거
- 배포 후 실제 개발 DB의 수집 실행·제안 저장·공개 목록 노출 확인

출연진·타임테이블·포스터/아티스트 이미지의 상세 저장과 공개 상세 API는 별도 상세 정보 작업에서 검증한다. 판매처 목록만으로 공개되지 않은 공연 시각을 추정하지 않는다.
