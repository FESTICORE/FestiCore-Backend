# 푸르지오 서운정 공식 프로필 사진

## 목적과 출처

- 문화체육관광부의 [제4회 푸르지오아트홀 뮤직페스티벌 안내](https://www.mcst.go.kr/site/s_culture/culture/cultureView.jsp?pRo=160&pSeq=75117)에 `서운정`이 출연진으로 등재되어 있다.
- [한국국제물류주선업협회(KIFFA) 홍보대사 페이지](https://www.kiffa.or.kr/sub05/sub04.php)는 같은 이름의 `소프라노` 프로필과 인물 사진을 한 항목 안에 게시한다. 두 출처가 같은 인물이라는 해석은 이름·성악 분야를 함께 확인한 근거에 따른다.
- 사진 파일 주소는 소스 설정에 고정하지 않는다. 서버가 매일 공식 HTML의 정확히 한 `서운정` 항목에서 현재 `img src`를 찾아 기존 이미지 저장소에 보관한다.

## 데이터와 공개 계약

- `artist-image`, `html-text`, 1440분 간격 소스를 등록한다. `parserConfig`는 전용 seed, 문화부 공연 URL, 저장된 출연진 이름 `서운정`만 포함한다.
- 이미 활성인 다른 사진 소스 또는 비활성 소스가 같은 공연·출연진으로 등록되어 있으면 마이그레이션을 중단한다.
- 파서는 공식 페이지 URL과 정확한 이름·분야·단일 이미지·허용된 HTTPS 호스트/경로를 모두 검사한다. 다른 사람의 사진, 여러 후보, 스크립트 URL, 이미지 경로의 쿼리 등은 거절한다.
- 공개 상세 `GET /api/v1/festivals/:id`의 `artists[].imageUrl`은 이미지가 실제 저장된 뒤에만 채운다. 이미지 다운로드 경로에도 동일한 출처 제한을 적용한다.
- 문화부 원본의 공연 신원·기간·장소·날짜별 출연진 검증이 성공한 푸르지오 항목에만 그 URL을 내부 `sourceUrls`에 연결해 저장 사진이 해당 축제에 한정되도록 한다.
- 기존 JSON API 응답 형태 `{code,data,message}`는 유지한다. 신규 엔드포인트는 없다.

## 검증

- 공식 HTML과 JPEG 응답을 직접 확인한다. robots 정책은 기존 `checkRobots`를 따른다.
- 파서 성공/실패, 공개 허용 정책, 소스 검증, SQL 매개변수 수와 충돌/비활성 처리를 테스트한다.
- `npm test -- --runInBand`의 해당 테스트, TypeScript 검사, lint, build, migration smoke를 실행한다.
- PR은 Draft로 열고 CI를 확인한다. 병합과 운영 저장 여부는 별도 검증한다.
