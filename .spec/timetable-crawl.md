# 공식 공연 시간표 수집

## 목표

- 등록된 모든 공연에 대해 주최사 웹사이트와 공식 Instagram 공개 게시물을 확인한다.
- 아티스트별 시작·종료 시간이 공식 원본에 있을 때만 축제 상세 API에 노출한다.
- 출처 URL, 원본 이미지, 수집 시각, 판독 실패 항목을 함께 보관한다.
- 매일 00:00 KST 예약 수집에 포함하고 소스별 변경을 다시 처리한다.

개발 카탈로그에는 2026-10-23 현재 18개 항목이 있다. 한 공연의 판매권종이나 판매처가 여러 항목으로 등록될 수 있으므로, 시간표는 판매처 URL마다 중복 입력하지 않고 확인된 공식 행사와 연결한다. 예를 들어 Anime X Game Festival은 3일권과 요일권으로 네 항목, COUNTDOWN FANTASY는 Mint Paper와 YES24 국문·영문으로 세 항목이다. 각 항목의 출처 URL에 동일한 검증 시간표를 매핑하되 날짜가 다른 권종은 해당 날짜만 보여준다.

그 외 등록 항목은 푸르지오아트홀 뮤직페스티벌, XMF, THE BRIDGE FESTIVAL, 썸띵 뉴 뮤직 페스티벌, 원웨이 페스티벌, FISM BUSAN 2028이다. 이 항목들도 공식 주최사/공식 공개 게시물에서 개별 공연 시각을 확인할 때 같은 수집 경로에 넣는다. 아직 확인되지 않은 시각은 빈 시간표로 유지한다.

공식 Instagram은 게시물 URL·계정 소유·이미지 원본을 검증한 경우에만 사용한다. 직접 조회가 HTTP 429를 두 번 반환해 같은 접근을 더 시도하지 않았다. 게시물이 있다고 추정해 시간을 생성하지 않는다.

GMF 공식 이미지 두 장은 2026-10-23 macOS Vision의 무대별 영역 OCR로 48개 시작 시간과 42개 종료 시간을 추출했다. 날짜·무대별 아티스트 48팀은 [주최사 최종 라인업](https://www.mintpaper.co.kr/posts/4802)과 대조했다. 검증 데이터는 `/private/tmp/gmf2026-verified-sets.json`, 출처는 `/private/tmp/gmf2026-verified-sets-sources.json`에 있다. 이 검증은 현재 GMF 이미지 레이아웃에 한정되며, Linux 서버의 Tesseract 수집 또는 자동 공개 성공을 뜻하지 않는다. 미공개 종료 시각 6개는 `null`이다. XMF 이미지는 공식 원본을 확인했지만 Linux OCR 결과와 공개 API 반영은 별도 검증이 필요하다.

## 수집 계약

1. 공연별 소스는 공식 페이지 URL, 출처 계정 또는 주최사, 축제 식별자, 날짜, 무대, 이미지 선택 규칙을 설정 데이터로 갖는다. 특정 공연 URL이나 시간을 애플리케이션 코드에 고정하지 않는다.
2. robots.txt와 HTTP 상태를 확인하고, 이미지 크기·형식·픽셀 수·사설 주소 차단 등 기존 크롤 보안 검사를 재사용한다.
3. 이미지 OCR은 좌표와 신뢰도를 보존한다. 여러 무대가 있는 원본은 무대 영역을 분리하고, 각 아티스트 카드에서 이름과 시간의 관계를 검증한다. 하나의 OCR 줄만으로 다른 카드의 시간을 연결하지 않는다.
4. 시작 시간만 있는 헤드라이너는 종료를 추정하지 않는다. 검증된 시간표의 종료 시간은 `null`로 공개한다.
5. 일반 공연과 사인회·토크 등의 부대행사는 구분한다. 아티스트별 시간이 없는 전체 행사 시간은 공연 세트로 만들지 않는다.
6. 이전에 발행한 시간표를 새 수집 실패로 지우지 않는다. 바뀐 원본의 확정된 차이만 제안/발행한다.
7. 이미지에서 추출한 행은 원본 해시와 파서 버전으로 중복 제거하고 `pending`으로 보관한다. 일부 행만 읽힌 경우에도 검토본을 남기고 예상 행 수를 관리자에게 표시한다. 관리자가 원본을 대조해 누락된 행을 추가하기 전에는 승인할 수 없다. 검증된 revision만 공개하며 검증 전 새 수집이 이전 검증본을 대체하지 않는다.
8. 공식 Instagram 자료도 게시물 URL과 계정 소유를 확인한 뒤 다른 이미지 원본과 동일한 검증 절차로 처리한다. HTTP 429나 접근 제한을 우회하기 위한 로그인 세션·대기열 조작은 사용하지 않는다.

## 검증

- GMF 공식 이미지 2장의 실제 OCR 결과를 좌표·카드 단위로 확인하고, 48개 음악 공연 및 종료 시간 누락 6개를 검증한다.
- 날짜·무대 혼동, 낮은 OCR 신뢰도, 엇갈린 카드, 종료 시간 누락, 비공식 계정, robots/429 실패 사례를 테스트한다.
- 개발 DB와 `GET /api/v1/festivals/:id`에서 시간표·출처·저장 이미지를 확인하고, 자정 예약 재실행에서도 변경분만 적용되는지 확인한다.

## 구현 경계

- `image-ocr` 시간표 소스는 공식 이미지 URL, 행사 URL, 공식 공지 URL, 날짜, 무대별 이미지 영역, 예상 행 수를 관리자 설정으로 등록한다. 기존 매일 00:00 KST 스케줄러가 활성 소스를 재수집한다.
- OCR 후보는 원본 이미지와 함께 `pending`으로 저장한다. 부분 인식도 보관하되 예상 공연 수를 채운 검토본만 승인할 수 있다. 관리자는 검토 API에서 전체 공연 목록을 교정하고 승인하거나 거절할 수 있다. 공개 상세 API는 `verified`만 읽는다.
- 새 시간표 이미지 게시물이나 공식 Instagram 게시물을 자동으로 발견하는 기능은 이 변경에 포함되지 않는다. 소스 URL 등록이 필요하다. 현재 Linux Tesseract에서 GMF 48개를 정확히 추출하는지는 배포 후 실제 실행으로 확인해야 한다.
