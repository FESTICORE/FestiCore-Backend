# 팩 발행·롤백 알림

- 팩 발행과 롤백을 완료하는 같은 DB 트랜잭션 안에서 `packUpdates=true`인 기기의 `pack.updated` 작업을 버전별 고유 키로 등록한다.
- 작업자는 구독·기기 토큰·현재 발행 버전을 전송 직전에 다시 확인한다. 오래된 버전 작업은 취소하고 APNs 일시 장애는 기존 재시도 정책을 따른다.
- `pushedDevices`는 APNs 수신 완료 수가 아니라 이번 발행으로 큐에 들어간 기기 수다.
- 팩과 버전 조회는 ETag 재검증을 요구한다. 새로 저장되는 공유 캐시는 오래된 팩을 한 시간 동안 제공하지 않는다. 기존 CDN 객체를 즉시 제거하는 퍼지는 아직 연결되지 않았다.
- 단위 테스트는 트랜잭션 쿼리 호출, 구독 철회·버전 변경 취소, 배경 푸시를 검증한다. 공개 API E2E는 캐시 헤더와 304를 검증하고 PostgreSQL CI는 마이그레이션을 검증한다. 실제 PostgreSQL에서 알림 `INSERT … SELECT … RETURNING` 실행은 별도 통합 검증이 남아 있다.
