# XMF 2026 출연진 사진

## 목표

- [XMF 공식 라인업](https://xmfestival.com/lineup)의 출연진별 사진을 매일 확인하고, 저장된 WebP만 공개 상세 API의 `artists[].imageUrl`과 `timetable[].imageUrl`에 노출한다.
- 축제 연결 키는 멜론 공연 상세 `https://ticket.melon.com/performance/index.htm?prodId=213766`으로 고정하고, 아티스트 이름은 공개 상세 응답에 실제 포함된 이름과 정확히 대조한다.
- 이미지가 없거나 공식 페이지와 이름의 대응을 확인할 수 없으면 `null`을 유지한다. 이미지 URL만으로 공연 시간이나 출연 사실을 추정하지 않는다.

## 수집 경계

- 출연진 이름이나 이미지 경로 목록을 코드 또는 마이그레이션에 고정하지 않는다. 공식 라인업 페이지의 개별 카드와 출연진 메뉴를 수집 시점마다 대조해 사진 URL의 소유자를 확정한다. 카드만 있고 이름과 연결할 수 없는 사진은 등록하지 않는다.
- 서버는 공식 페이지의 카드에서 모달 ID와 이미지 URL을 읽고, 공식 모달의 이름이 확인된 카드만 개별 수집 소스로 등록한다. 다음 예약 실행에서 카드가 바뀌면 경로 설정도 갱신한다.
- 개별 수집기는 원본 페이지에서 사진 경로의 고유 부분을 다시 찾고 robots 정책, MIME, 실제 이미지 디코딩 및 크기 제한을 통과한 파일만 WebP로 저장한다.
- [공식 최종 라인업 공지](https://xmfestival.com/notice)의 연도·공연 날짜·양일 출연 팀 수가 검증되면 `한글(영문)` 표기를 별칭 후보로 읽는다. 공지 연도는 수집 소스의 `expectedYear`와 일치해야 한다. 영문명은 같은 공연에 연결된 공식 갤러리 사진 소스의 `artistName`과 NFKC·공백·대소문자 정규화 후 정확히 같아야 하며, 다른 사진 소스의 이름이나 별칭과 충돌하면 연결하지 않는다.
- 자동 별칭은 `artistAliasSource=official-notice`로 출처를 기록한다. 공지가 바뀌거나 사진 소스가 비활성화되면 해당 자동 별칭을 정리한다. 관리자가 직접 수정한 별칭은 자동 수집이 덮어쓰지 않는다. 공지 본문이 이전 실행과 같더라도 늦게 등록된 갤러리 사진을 연결한다.
- 개발 환경에서 소스 수집 후 축제 상세 응답의 저장 이미지 URL, 타임테이블 행 연결, 이미지 HTTP 200을 확인한다.

## 검증

- 갤러리 테스트는 모달의 이름과 카드 이미지가 함께 연결되는지, 잘못된 모달·외부 이미지·중복 이름이 반영되지 않는지 확인한다.
- 공인된 시간표의 표기와 모달 이름이 다르면 직접 확인된 별칭만 연결한다. 단순 부분 문자열 추정은 사용하지 않는다.
- 출처가 없는 아티스트와 시각이 표기되지 않은 EMNW는 사진 작업 때문에 시간표에 추가하지 않는다.
- PR 검사, 개발 배포, 실제 수집 실행, 공개 API 검증을 각각 별도로 기록한다.
