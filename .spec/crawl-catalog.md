# 수집 축제 공개 목록

`GET /api/v1/festivals`는 발행된 축제와 티켓 판매처·공식 주최자 사이트에서 발견했으나 팩 검증이 끝나지 않은 축제를 함께 반환한다. 발견 항목은 `status: "discovered"`, `packVersion: 0`, `flagsEnabled: false`, `sourceUrl`로 구분한다. 보관된 공식 포스터가 있으면 `thumbUrl`은 공개 WebP 경로이며, 없으면 `null`이다. `firstDate`와 `lastDate`는 출처에 적힌 **행사 날짜**이며 실제 시작·종료 시각을 뜻하지 않는다. 발견 항목의 `/pack`은 404이며, 앱은 `packVersion > 0`일 때만 팩을 요청한다.

미검증 공연 시각이나 스테이지를 만들어 발행하지 않는다. 관리자에게 거절된 항목은 공개 목록에서 빠진다. 같은 출처 URL이 발행되면 발견 항목은 발행 항목으로 교체된다. 출처에서 수집한 제목·장소·URL·날짜와 직접 확인한 행사 `officialInstagramUrl`만 투영하고 원문 HTML과 내부 메타데이터는 반환하지 않는다. 주최자 공통 계정과 아티스트 계정을 행사 계정으로 표시하지 않는다.

목록의 ETag와 커서는 발행·발견 항목을 모두 포함해 계산한다. 앱은 마지막 성공 응답과 발행 팩을 로컬에 저장하고, 재연결 시 ETag·팩 버전으로 갱신한다. 오프라인 동안 서버의 새 데이터를 기기에 전달할 수 없으며, 기존 저장 데이터로 조회를 이어간다.

검증: 개발 DB의 수집 제안이 6건이고 발행 팩이 0건일 때 목록에 유효한 발견 항목이 나타나야 한다. 형식이 잘못된 날짜·URL, 거절된 항목, 중복 판매차수, 발행된 동일 URL은 제외하거나 병합한다. 페이지네이션과 ETag를 확인한다.
