# 공연 상세의 출연진 수집 (#133)

## 목표

- YES24·NOL 상세의 공식 Event 구조화 데이터에 `performer`가 있을 때 공연 후보의 `artists`로 저장한다.
- 원본에 출연진 이름이 없으면 목록을 비워 둔다. 공연 전체 시간, 라인업 나열 순서, 이미지 위치로 개별 시작 시각을 만들지 않는다.
- 악의적인 이름을 제외하고 공연자 객체의 링크·이미지는 저장하지 않는다. 다른 공연의 별도 Event를 병합하지 않는다.

## 검증

- 공연 상세 Event의 단일/배열 공연자, 중복, 깨진 입력과 링크 미저장을 검사한다.
- 실제 티켓 사이트에서 HTTP 접근이 거절되면 크롤 실행 성공으로 주장하지 않는다. 공식 접근 가능한 대체 출처가 확보될 때 별도 소스를 연결한다.
- 공연별 시작 시각은 공식 시간표 또는 공식 공지에서 시각과 출연진을 함께 확인한 뒤 시간표 검토 절차를 거쳐 공개한다.
